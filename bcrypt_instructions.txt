=== Generating a BCrypt Password Hash ===

From your terminal, navigate to the `backend/` directory and run:

node -e "console.log(require('bcryptjs').hashSync('your_password_here', 12))"

Replace 'your_password_here' with the password you want to hash.

---------------------------------------------------
JavaScript implementation (Node.js):

const bcrypt = require('bcryptjs');
const hash = bcrypt.hashSync('your_password_here', 12);
console.log(hash);
